## 개요
- **소속** 피로그래밍 21기 개발 · 22기 운영진
- **인원** 5명
- **역할** 면접관 코멘트 기능 개발, 서버 운영


## 기술 스택
Python · Django · PostgreSQL · AWS EC2·ALB·Auto Scaling · Nginx · GitHub Actions

## 핵심 문제 해결

### 1. 모집 전 부하 테스트에서 발견한 단일 서버 한계
- **문제** 모집 기간 접속 집중에 대비한 부하 테스트에서 동시 접속이 늘자 단일 EC2 서버가 다운됨
- **판단** 한 대의 사양을 올리는 수직 확장만으로는 몰리는 요청을 감당하기 어렵다고 판단
- **해결** ALB와 Auto Scaling 그룹을 구성해 트래픽에 따라 서버가 늘어나는 수평 확장 구조로 전환 (실제 모집 전 적용)

### 2. 면접관 평가 코멘트 기능
- 지원자별 면접관 코멘트를 AJAX로 새로고침 없이 등록·삭제

## 팀 작업
- 코멘트 기능, 지원자 상세·면접 일정 화면은 본인 구현
- 자동 배포(GitHub Actions → EC2)는 팀과 함께 운영
