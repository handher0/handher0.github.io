## 개요
- **소속** 슈어소프트테크 현장실습
- **역할** 웹 기반 사내 도구 풀스택·AI

*사내 도구라 코드·화면은 공개하지 않고, 구조만 설명합니다.*

## 기술 스택
Python · Flask · React · SQLAlchemy · Trace32 Remote API · LangChain · Qwen(SFT·DPO) · MCP

## 배경
기존에는 엔지니어가 장비 앞에서 테스트 코드를 직접 작성해 빌드하고, 결과를 수동으로 확인했습니다.

## 핵심 문제 해결

### 1. 원격 검증 자동화
- 테스트 생성 → 빌드 → 실행 → 평가서 작성을 웹에서 원격으로 한 흐름으로 자동화
- 결과: 암복호화 모듈 검증의 빌드 횟수 24회 → 1회, 장비 위치와 무관한 원격 검증

### 2. 파인튜닝 실패 → MCP 기반 도구 호출 구조로 전환
- **시도** RAG 구성 후 로컬 LLM(Qwen)을 20,000건 데이터로 SFT·DPO 파인튜닝
- **문제** 생성된 스크립트가 사양 조건을 빠뜨리거나 같은 요청에도 결과가 달라짐
- **전환** AI는 무엇을 할지 판단만, 실행은 검증된 코드가 맡도록 역할 분리
  - Python MCP SDK로 서버를 만들고 Trace32 원격 제어 API를 연결·실행 제어, 메모리·레지스터, 브레이크포인트, 변수·심볼 조회, 스크립트 실행 단위 도구로 등록
  - 서버 지침으로 도구 호출 순서를 안내하고, 오류 시 원인과 다음 조치를 함께 반환
- **결과** 자연어 검증 요청부터 실행까지 AI 에이전트로 연결해 팀에 시연, 실무 도입
