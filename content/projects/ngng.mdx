## 개요
- **소속** 숭실대학교 시스템소프트웨어 연구실 학부연구생
- **역할** 백엔드·AI 파이프라인

*연구실 비공개 저장소라 코드 링크는 제공하지 않습니다.*

## 기술 스택
Python · FastAPI · PostgreSQL · SQLAlchemy · Celery · Redis · SSE · Docker

## 서비스 흐름
```
손글씨 업로드 → [1단계] YOLO 자소 분리(약 7분) → [2단계] 디퓨전 폰트 생성(약 3분) → 폰트 다운로드
```

## 핵심 문제 해결

### 1. 단일 태스크를 2단계 파이프라인으로 분리 — 재생성 소요 70% 단축
- **문제** 자소 분리와 폰트 생성을 태스크 하나로 약 10분 동안 연달아 실행 → 실패하거나 재생성할 때 처음부터 다시 실행
- **해결** 두 단계를 별도 Celery 태스크로 분리하고 중간 산출물을 저장. 재생성은 생성 단계만 다시 실행
- **결과** 재생성 소요 약 10분 → 3분 (자소 분리 7분 생략, 70% 단축)

### 2. 진행률 실시간 전달
- 요청은 즉시 접수(202)하고, Redis 기반 진행률 추적과 SSE로 단계별 상태를 전달

### 3. 출시 일주일 전 자소 분리 결함
- 반복되는 생성 실패의 원인을 모델팀과 함께 좁혀 전처리 단계의 자소 분리 실패로 규명
- 즉시 조치(OpenCV 전처리 조정)와 근본 개선(모델팀 분리 로직 강화)을 나눠 출시 전 해결

## 팀 작업
- 비동기 파이프라인·SSE는 팀원과 함께 구현, 재생성 로직·쿠폰 발급·자소 분리 결과 API는 본인 구현
- AI 모델은 연구실 석사 연구원(모델팀) 담당
